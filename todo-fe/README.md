# Todo Frontend

React ile yazılmış arayüz. Kurulum ve Docker ile çalıştırma için
[ana README](../README.md) dosyasına bak.

Yerelde çalıştırmak için:

    npm install
    npm start

Arayüz `http://localhost:3000` adresinde açılır. Backend adresi
`REACT_APP_API_BASE_URL` ortam değişkeniyle verilir (tanımlı değilse
`http://localhost:8300/api/todos` kullanılır).
